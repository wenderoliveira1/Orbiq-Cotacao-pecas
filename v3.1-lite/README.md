# Orbiq V3.1 Lite

Versão enxuta do aplicativo de orçamentos e cotações da Orbiq.

## Destaques
- Tema claro/escuro
- Novo orçamento rápido
- Serviços com sugestão automática de peças quando aplicável
- Funilaria com seleção rápida por partes do veículo
- Peças adicionais
- Impressão/PDF
- Ranking semanal e mensal
- Mão de obra com cadastro manual e lista inicialmente vazia
- Cotações e fornecedores
- Novo orçamento após finalizar

## Privacidade
Este diretório não inclui contatos reais de fornecedores. Os dados reais devem permanecer apenas na instalação privada do Google Sheets/Apps Script.

## Arquivos
- `Code.gs`
- `Index.html`

Execute `setupApp()` uma vez após substituir os arquivos no projeto Apps Script e depois publique uma nova versão do Web App.
